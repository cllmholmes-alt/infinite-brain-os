## Cross-repo facts

1. **The capacity-aware execution layer** is the central architectural concept.
   It appears in the dashboard app README as Augment/Guide/Carry, in the
   Figma Cognitive Visual Canon as FLOW/FRAGILE/LOW_ENERGY/OVERLOADED, and
   in the website full-system spec as HIGH/MEDIUM/LOW capacity modes. All
   three are converging on the same idea: the UI adapts its density and
   decision surface to the user's current cognitive state.

2. **The calm, institutional posture** is consistently applied across all
   sources. The dashboard app prohibits gradients, neon, glassmorphism,
   gamification, and KPI overload. The Figma canon enforces warm red at
   severity 3 ("not alarming"), no flash, no bounce, no elastic overshoot.
   The landing page spec requires that the page "stabilize the visitor before
   it sells anything."

3. **Component architecture**: The Master Reference Database is the
   content/design reference. The Artsyled Website is the public conversion
   surface and authenticated web dashboard, generated from the Figma source
   of truth. The Figma dashboard app is the main development repo with the
   Expo mobile app, Apple Watch app, Supabase backend, Agentic-OS control
   plane, and governance system. The Money Website is planned but not yet
   implemented. The Alternative Design directory is empty.

4. **Figma as the source of truth**: The Figma design at
   `https://www.figma.com/design/QNmiv2oZ9Jyz08orjDb7Cl/The-New-ADHD-OS` is
   the canonical visual authority. The Artsyled Website was generated from it
   via Figma Make. The Figma file architecture blueprint specifies three
   permanent files (Design System, Core App, R&D Lab) mirroring the monorepo
   structure. Design tokens must map 1:1 between code and Figma. The master
   Figma spec document is the "Cognitive Visual Canon" -- a 2048-line design
   system document covering the full cognitive state model, layout rules,
   overwhelm recovery, design tokens, motion system, interaction choreography,
   accessibility canon, and UX writing canon.

5. **Tech stack unification**: React + TypeScript + Tailwind CSS + Zustand +
   Supabase across both the website and the dashboard app. The dashboard app
   adds Capacitor for native iOS/Android, Apple Watch (Swift), and a deep
   governance/audit/autonomy layer.

6. **The founding claim** is consistent: "Cognitive load is a structural
   issue, not a moral failing." This appears verbatim in the dashboard app
   README and is the load-bearing pillar for all product decisions. The
   website redesign spec translates this into "Your brain isn't broken. Your
   system is overloaded."

7. **Prohibited and required patterns**: No streaks, no shame, no gamification,
   no diagnostic claims, no medical claims, no urgency cues. One primary
   action per screen. Start Here dominates as the Next Best Action. Capacity
   adapts density downward, never upward under load.
