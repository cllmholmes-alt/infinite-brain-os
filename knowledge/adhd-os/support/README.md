# Support: adhd-os

This folder holds provenance and migration records for the ADHD-OS namespace.

## What goes here

- Ingestion receipts: records of what content was copied from which ADHD-OS repo, when, and
  by whom, when source material is brought into the namespace.
- Source-priority tables: when the repos or the Figma source disagree, which one takes
  precedence and why.
- The Figma design link and any export provenance.

## What does not go here

Derived thinking goes in `synthesis/`. Knowledge nodes go in their respective folders. Do
not put analytical content in `support/`.

## Boundary note

`support/` is mechanical and historical. `synthesis/` is interpretive and current. This
boundary is strict.

## Current state

This folder is seeded with this README only. It grows as content is ingested from the
ADHD-OS repos during later phases.
