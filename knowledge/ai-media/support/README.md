# Support: ai-media

This folder holds provenance and migration records for the ai-media namespace.

## What goes here

- Ingestion receipts: records of what content was copied from which AI-media repo, when, and
  by whom, when source material is brought into the namespace.
- Source-priority tables: when the repos or external documentation disagree, which one takes
  precedence and why.
- Model provenance: records of which models were downloaded, from where, and with what
  licenses, as the toolchain is documented.

## What does not go here

Derived thinking goes in `synthesis/`. Knowledge nodes go in their respective folders. Do
not put analytical content in `support/`.

## Boundary note

`support/` is mechanical and historical. `synthesis/` is interpretive and current. This
boundary is strict.

## Current state

This folder is seeded with this README only. It grows as content is ingested from the
AI-media repos during later phases.
