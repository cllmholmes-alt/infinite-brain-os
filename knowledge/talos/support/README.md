# Support: talos

This folder holds provenance and migration records for the TALOS namespace.

## What goes here

- Ingestion receipts: records of what content was copied from the TALOS repo, when, and by
  whom. This is the home for the provenance of any `TALOS_SYSTEM_LAW.md` content brought into
  the namespace.
- Source-priority tables: when the TALOS repo and the brain's own doctrine disagree, which
  one takes precedence and why.
- Pointers to the binding law file in the TALOS repo (never a copy that could drift).

## What does not go here

Derived thinking goes in `synthesis/`. Knowledge nodes go in their respective folders. Do
not put analytical content in `support/`.

## Boundary note

`support/` is mechanical and historical. `synthesis/` is interpretive and current. This
boundary is strict.

## Current state

This folder is seeded with this README only. It grows as content is ingested from the TALOS
repo during later phases.
