# Support: game-modding

This folder holds provenance and migration records for the game-modding namespace.

## What goes here

- Ingestion receipts: records of what content was copied from which game-modding repo, when, and
  by whom, when source material is brought into the namespace.
- Source-priority tables: when the repos disagree on a design direction, which one takes
  precedence and why.
- Tool README provenance and package-manifest snapshots.

## What does not go here

Derived thinking goes in `synthesis/`. Knowledge nodes go in their respective folders. Do not put
analytical content in `support/`.

## Boundary note

`support/` is mechanical and historical. `synthesis/` is interpretive and current. This boundary
is strict.

## Current state

This folder is seeded with this README only. It grows as content is ingested from the
game-modding repos during later phases.
