# ADHD-OS

## Summary

ADHD-OS is a behavioral executive-function operating system built to reduce cognitive load
rather than capture attention. Its doctrine, taken from the dashboard app, is "calm,
institutional, cognitive load-reducing," with the operating principle that cognitive load is
a structural issue, not a moral failing. The brand is the operator's flagship consumer
product and the first target for a dedicated knowledge namespace.

## Type and scope

- `party_type`: brand
- primary scope: a product brand the operator owns and ships
- components: a capacity-aware execution layer, a Figma-defined design system, two public
  websites, and a mobile (Expo) dashboard app
